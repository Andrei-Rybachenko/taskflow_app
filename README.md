# TaskFlow

Веб-приложение для управления командами, задачами, встречами и оценками.

## Возможности

- REST API (`/api/...`): задачи, команды, участники, комментарии, оценки, встречи, календарь.
- Веб-интерфейс (`/ui/...`): вход, регистрация, команды, задачи, встречи, профиль.
- Админка SQLAdmin: управление сущностями в браузере.


## Технологии

- FastAPI
- FastAPI-users
- PostgreSQL
- SQLAlchemy
- Pytest
- Alembic
- Jinja2
- Black
- Flake8

## Переменные окружения

Создайте файл `.env` по образцу файла `.env.example`.
Настройки читаются из `src/config.py` (класс `Settings`).

## Запуск приложения в Docker-контейнере

```bash
    docker compose up --build -d 
```
Суперпользователя можно создать в админ-панели. 

# Запуск приложения локально на машине 

## Установка зависимостей

Проект описан в `pyproject.toml`.

```bash
poetry install
```

Либо установите зависимости вручную через pip из секции `[project]` в `pyproject.toml`.

## Миграции базы данных

Используется Alembic. Команды выполняйте из корня репозитория.

```bash
alembic upgrade head
```

## Запуск приложения

```bash
uvicorn src.main:app --reload
```

- Корень `/` перенаправляет на `/ui/login`.
- Документация API: `/docs` (Swagger) и `/redoc`.

## Тесты

Тесты используют SQLite в памяти и httpx.

```bash
pytest tests/
```

## Структура проекта 

| Путь | Назначение |
|------|------------|
| `src/main.py` | Точка входа FastAPI, подключение роутеров и админки |
| `src/routers/` | API и веб-UI |
| `src/services/` | Бизнес-логика |
| `src/repositories/` | Доступ к БД |
| `templates/` | Шаблоны Jinja2 для `/ui` |
